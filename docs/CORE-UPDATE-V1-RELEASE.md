# AI-Verse Core Update v1 Release

Released: 2026-10-12
Core released on this date: `core-first-run-rc1-2026-10-12`
Previous Core: `core-stable-2026-10-10`

The first preservation-safe Core update path was released on the date above. This page records that historical release and transition. For the current default Core, use the [release catalog](../src/aiverse_distribution/catalog/core_promotions.json) (`current_release`); the normal installer selects it automatically.

## Update AI-Verse

Inside AI-Verse, ask:

> Update AI-Verse.

Or run:

```text
aiverse update
```

No release ID, Git SHA, repository path, reinstall, reset, or delete step is required.

The updater changes only admitted AI-Verse software. It preserves member-owned profile/preferences, goals/direction, memories/decisions, workspaces/project history, Data/connections, custom files, personal skills, automations, and extensions. If ownership or local modification is ambiguous, the update stops instead of overwriting it.

The released transition is:

`core-stable-2026-10-10` -> `core-first-run-rc1-2026-10-12`

Only `ai-verse-os` changes in this release. Brain, Memory, Skills, and Data remain pinned to the previous stable revisions.

Reverse rollback to `core-stable-2026-10-10` is not advertised or admitted because no separate reverse preservation qualification exists.

The release was qualified with populated preservation acceptance on macOS, Linux, and Windows, plus a successful update of the owner's real populated installation with final status, doctor, and updater health PASS.
