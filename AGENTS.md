# AI-VERSE for Codex

This repository contains the portable AI-VERSE operating layer. Read `AI-VERSE.md` before acting, then read the project's `project-state/PROJECT.md` and `project-state/WORK.md` when they exist.

## Rules

- Treat AI-VERSE as an overlay on Codex, not a replacement for Codex or its built-in skills.
- Use the skills under `.agents/skills/` when their descriptions match the task.
- Do not copy or rewrite Codex's built-in skills into this repository.
- Keep provider credentials, sessions, memories, and local configuration outside the repository.
- Record durable project facts and work results in project state, not in this instruction file.
- Ask the owner before changing purpose, access, licensing, privacy boundaries, or major scope.
- Verify work before reporting it as complete.
