# AI-VERSE Onboarding

Create the smallest useful starting context for AI-VERSE.

## Procedure

1. Ask for the owner's desired outcome, audience, working style, and first useful result.
2. Separate verified facts, owner preferences, assumptions, and unanswered questions.
3. Ask which tools or connections are approved; record names and purposes only, never credentials.
4. Create or update `project-state/PROJECT.md` and `project-state/WORK.md` from verified facts.
5. Propose one first workflow and one clear success check.
6. Show the owner what was recorded and what remains unanswered.

## Rules

- Never infer private identity, business facts, permissions, or goals.
- Never copy memories, sessions, credentials, runtime databases, or a host profile into project state.
- Do not install host skills just because they exist; select only a needed capability.
- Stop at an owner decision instead of filling a gap with a guess.
