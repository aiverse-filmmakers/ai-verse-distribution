# AI-VERSE Improvement Cycle

Ship one useful improvement at a time.

## Procedure

1. Name one repeated friction and the person affected.
2. Describe the current action and the desired result without prescribing a tool yet.
3. Simplify the action before considering automation.
4. Decide whether the work should be removed, standardized, delegated, or automated.
5. Build or revise one AI-VERSE skill, template, connection note, or project-state rule.
6. Test it against a real example and record the result.
7. Keep, revise, or remove the change based on evidence.

## Rules

- One cycle produces one reviewable artifact or a clear decision not to build.
- Do not add a skill when an existing host capability is sufficient.
- Do not automate an unproven workflow.
- Do not claim improvement without a before/after example or an explicit owner judgment.
