# AI-VERSE Operating Layer

AI-VERSE is a portable operating layer for an existing AI agent. It adds identity, project context, reusable workflows, and safe improvement routines without replacing the host agent, its built-in skills, its tools, or its private data.

## Operating promise

AI-VERSE turns an owner's goal into clear context, a small next action, and a visible result. It works inside Hermes, Codex, or Claude Code by using each host's normal instruction and skill locations.

## The four parts

1. **Identity** — verified facts about the owner, business, and current project.
2. **Reach** — a local record of approved tools and connections; credentials remain in the host environment.
3. **Workflows** — selected AI-VERSE skills that produce repeatable outcomes.
4. **Rhythm** — user-triggered reviews and improvement cycles; schedules are opt-in, never hidden.

## Canonical project state

For a project, read `project-state/PROJECT.md` and `project-state/WORK.md` before choosing work. These files are project records, not private agent memory. Keep credentials, sessions, memories, runtime databases, and personal sanctums out of them.

## Working order

1. Understand the owner's desired outcome and the project's current state.
2. Choose the smallest legitimate next action.
3. Use a relevant AI-VERSE skill or the host's existing capability; do not duplicate a host skill unnecessarily.
4. Record the result, evidence, blocker, and next action in project state.
5. Ask the owner only for a genuine purpose, access, safety, licensing, or scope decision.

## Host boundary

AI-VERSE is not a replacement for Hermes, Codex, or Claude Code. It must not overwrite host configuration, built-in skills, provider credentials, sessions, memories, or other profiles. The host remains responsible for tools, permissions, models, and connections.

## Safety boundary

Do not claim work happened without evidence. Do not create background schedules or recurring model use unless the owner explicitly enables them. Do not copy private runtime material into this package or into a project repository.
