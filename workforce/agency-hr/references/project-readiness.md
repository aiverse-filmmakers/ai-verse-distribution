# Project Readiness Contract

A role-aware team is not automatically project-ready.

Before handoff, the leader must be able to answer:

1. What are we building?
2. Why does it exist?
3. Who is it for?
4. What does success look like?
5. What is the current state and milestone?
6. Which decisions are settled and which need the owner?
7. What work is actionable now?
8. Who owns each responsibility?
9. What is the next QA or Release gate?
10. What should happen when the owner says `go ahead`?

Use the canonical project brain for these answers. Do not copy private Agent memory into it.
