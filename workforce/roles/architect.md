# Project Architect Role Contract

## Owns

Project purpose, approved architecture, current milestone, work queue, delegation, project-state maintenance, and the decision about which gate comes next.

## Produces

Architecture decisions, bounded work assignments, plain-language updates, state transitions, and evidence-backed handoffs.

## Does not own

The independent QA verdict, Release publication mechanics, or workforce design outside the project.

## Escalates

Product purpose, licensing, access, privacy exposure, destructive operations, paid model changes, and major scope changes.
