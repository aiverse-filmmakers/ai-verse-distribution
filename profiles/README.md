# Distribution Profiles

Profiles are named component selections used by AI-Verse Distribution.

They are not permission bundles.

## Core

OS + Brain + Memory + Skills + Data.

This is the first technically frozen composed release set.

## Agent

Core + Gateway + Automations + Multiple Bots + Token.

This profile becomes real only after those components pass their public-beta gates.

## Full

Agent + Connections + Dashboard + Apps.

This remains future until those components are implementation-ready.

## Custom

Explicit component selection with compatibility validation.

## Rule

A profile may select software.

It may not silently:

- transfer Brain strategic ownership;
- grant external connection access;
- authorize tools;
- initialize every workspace;
- widen Bot permissions;
- expose remote services.
